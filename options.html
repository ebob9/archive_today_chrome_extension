Archive.today Helper (Unofficial)

Right-click a web link to submit it or search for existing snapshots.

Custom submit destination
Custom search destination

Both default to archive.is. Choose another domain if one is unavailable in your region.

Custom URLs are built as origin + before-link text + link + after-link text. Choose URL-encoded for a link inside a query parameter; choose Raw URL for archive.today's search path.

Custom actions send links to the destination you enter. Only use a service you trust. Custom text is synced through Chrome; do not put passwords or secret tokens in these settings.

Submit uses the archive homepage entry point. If needed, finish the save or CAPTCHA there; a new snapshot is not guaranteed.

Each action sends the selected link to your chosen service in a new tab. Links can contain private information; only submit links you want to share with that service. Your preferences may sync through Chrome.

An independent hobby project, unaffiliated with archive.today. Open source under the MIT license.
